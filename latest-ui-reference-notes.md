# Latest UI reference notes

The latest Master Inventory reference is 1230×350. Its main content begins at x≈31 and ends at x≈1198, with the search block occupying the left section and the Category and Company controls placed as equal, compact fields on the same vertical baseline. The search field is intentionally narrow in the reference, but the label, field, helper text, and matching-assets count are left-aligned and internally balanced.

The visible issue in the current implementation is not simply the search width; it is the composition: search/helper/count form one left block, category/company form the middle, and Filters/action buttons form a compact right block. These blocks should not be stretched across a single oversized grid where empty gaps push actions away from the fields. A three-zone flex/grid layout with a fixed-width actions zone is a closer match.
The right action zone is compact and grouped as Filters, Export Excel, Non-working, Add item, with each button matching height and the “Showing all inventory” helper aligned beneath the right edge. The sidebar reference uses a narrow 298px mobile crop with a compact brand header, a clear divider before Workspace, regular nav row heights, a separate Offices label, and office rows that use the same left inset and badge alignment. The main issue to solve is reducing large empty space between the left field block and the action group while preserving the current sidebar hierarchy.
